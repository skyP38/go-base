# Ticket Processor

Проект обработки и фильтрации рабочих тикетов на языке Go.

## Структура проекта

```
ticket-processor/
├── main.go       # Первая версия (простая реализация)
├── exam.go       # Улучшенная версия с контекстом и интерфейсами
└── README.md     # Этот файл
```

## Формат данных

Тикеты представляются в формате:
```
TICKET-<ID>_<Пользователь>_<Статус>_<Дата>
```

Пример:
```
TICKET-12345_Паша Попов_Готово_2024-01-01
TICKET-12346_Иван Иванов_В работе_2024-01-02
```

### Поддерживаемые статусы:
- `Готово`
- `В работе`
- `Не будет сделано`

## Сравнение версий

### Версия 1 (`main.go`)
**Простая реализация**:
- Функция `GetTasks` принимает строку и фильтрует тикеты
- Базовая валидация формата
- Фильтрация по пользователю и статусу
- Простая обработка ошибок

**Использование**:
```go
user := "Паша Попов"
tasks := GetTasks(chatHistory, &user, nil)
```

### Версия 2 (`exam.go`)
**Улучшенная реализация**:
- Поддержка контекста для таймаутов и отмены
- Работа через интерфейсы `io.Reader`/`io.Writer`
- Детализированные кастомные ошибки
- JSON-сериализация результатов
- Модульная архитектура

**Использование**:
```go
ctx := context.Background()
input := strings.NewReader(chatHistory)
var output strings.Builder

err := GetTasks(ctx, input, &output, &user, nil, 5*time.Second)
```

## Архитектура версии 2

### Компоненты:
1. **`GetTasks`** - основная функция-оркестратор
2. **`readDataWithContext`** - потоковое чтение с поддержкой контекста
3. **`parseTickets`** - парсинг и валидация тикетов
4. **`parseTicketLine`** - парсинг одной строки с детальной валидацией
5. **`filterTickets`** - фильтрация по критериям
6. **`writeResult`** - запись результатов в JSON

### Ошибки:
```go
var (
    ErrInvalidFormat   = errors.New("неверный формат строки")
    ErrInvalidStatus   = errors.New("неверный статус")
    ErrInvalidDate     = errors.New("неверный формат даты")
    ErrInvalidTicketID = errors.New("неверный формат ID тикета")
)
```

```go
chatHistory := `

`

user := "Паша Попов"

```

```go
ctx := context.Background()
input := strings.NewReader(chatHistory)
var output strings.Builder

// Поиск всех задач в работе
status := "В работе"
err := GetTasks(ctx, input, &output, nil, &status, 10*time.Second)

if err != nil {
    log.Fatal(err)
}

fmt.Println("Результат:", output.String())
```
